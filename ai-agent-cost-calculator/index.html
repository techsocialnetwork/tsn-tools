    How it is calculated

    • Agent loop: with N tool calls the model is called N+1 times. Every call re-reads the whole context, so input grows by “tokens per tool call” each turn: input = (N+1) × base + tokens × N(N+1)/2. Untick the checkbox to bill tool tokens once instead.
    • Output: your average output per task, priced at the model’s output rate.
    • Caching: the % you enter is billed at the model’s cache-hit price instead of the normal input price. Cache writes cost extra on some vendors (Anthropic charges 1.25x for a 5-minute write) and cache storage is charged separately by Google; neither is included, so high cache shares are optimistic.
    • Retries: adds that % of the whole task cost again.
    • Month = per-day cost × days per month.
    • Long prompts: several models charge more above a context size (for example 200k tokens). The calculator warns when one call may pass that line but still uses the standard rate.
