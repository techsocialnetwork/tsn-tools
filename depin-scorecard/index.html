Notes: sources, gaps and caveats

  1. Prices & supply: CoinGecko free API, /coins/markets. Flux is listed on CoinGecko as “zelcash” (symbol FLUX). Rate limits are shared; if CoinGecko throttles you the page shows the last cached values and says so.
  2. Flux nodes: api.runonflux.io/daemon/getfluxnodecount, the same endpoint the Flux Dashboard uses. Tiers: Cumulus, Nimbus, Stratus.
  3. Akash providers: the provider list the Akash Dashboard reads through a CORS proxy hosted on tsnmedia.org (Akash’s own console API blocks browser requests). Counts are computed in your browser: “online” uses the provider’s own isOnline flag; GPUs and leases are summed over online providers only. If that proxy is retired, this card will show an error.
  4. Helium: entities.nft.helium.io/v2/hotspots/pagination-metadata for the IoT and Mobile subnetworks. These are registered hotspots (gateways), not necessarily online or earning, and the two subnetworks are different hardware fleets, so they are not added together.
  5. Filecoin: Filfox public /api/v1/overview. Raw byte power is shown in EiB (260 bytes); quality-adjusted power also counts verified-deal multipliers.
  6. Theta: Theta Explorer public API /api/stake/totalAmount for THETA and TFUEL stakes. The node count is the number of stake holders/nodes the explorer reports; it is not the number of GPU edge nodes. Theta’s EdgeCloud GPU capacity has no public keyless endpoint, so it is n/a.
  7. Render: network metrics n/a. The Render Foundation’s dashboard (stats.renderfoundation.com) shows frames rendered and node counts, but only inside a rendered web page with no API and no CORS headers, so a browser page on another domain cannot read it. Only the CoinGecko market data is live.
  8. io.net: network metrics n/a. The io.net IO Explorer API needs an account token, and the keyless device endpoint we found does not send CORS headers, so browsers block it. Only market data is live.
  9. Not investment advice. TSN does not recommend any token. Data may be delayed, incomplete or wrong; check the source before relying on a number.
